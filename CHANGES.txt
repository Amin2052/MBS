MBS Online Phase — modified files

RETIRED (see cloudflare/ migration): The self-hosted MBS Cloud Gateway
(server/index.js, whole-database-file upload/download) has been retired in
favor of the Cloudflare Worker + D1 path under cloudflare/. The old server
code is kept for reference at _retired/server-self-hosted-gateway/ but is no
longer wired into the app (no npm script, no IPC handlers, no UI). It stored
each workspace as a flat SQLite file on a self-hosted Node process, which is
a fundamentally different (and incompatible) model from Cloudflare D1's
relational storage, and the two were never meant to run side by side.

Added (still active):
- Cloud config and encrypted API-key storage (electron/main/cloud/cloud-config-service.ts)
- Row-level cloud record sync against the Cloudflare Worker's /v1/data/:collection API
- Online internal messaging bridge
- Online user directory sync
- Cloud settings UI in Settings > Integrations

The desktop app remains offline-first. Row-level sync to the Worker runs automatically every
15 seconds while Cloud sync is enabled in Settings > Integrations; messaging uses the same
Worker.
