| File | Purpose |
|-------|---------|
| `package.json` | Defines project metadata, dependencies, Electron Builder metadata, and development/build scripts. |
| `tsconfig.json` | Enables strict TypeScript settings, establishes compiler behavior, and configures path aliases for a scalable codebase. |
| `tsconfig.node.json` | Provides a dedicated TypeScript configuration for Node-based tooling and build configuration files. |
| `vite.config.ts` | Configures the Vite renderer build and establishes renderer-side module aliases. |
| `electron.vite.config.ts` | Defines the Electron build configuration for the main, preload, and renderer processes in a unified build system. |
| `tailwind.config.ts` | Configures Tailwind CSS content scanning and serves as the future foundation for application styling. |
| `postcss.config.js` | Enables Tailwind CSS and Autoprefixer within the build pipeline. |
| `.gitignore` | Prevents generated files, dependencies, environment files, and platform-specific artifacts from being committed to version control. |
| `.editorconfig` | Enforces consistent editor behavior across development environments. |
| `.prettierrc` | Defines consistent automatic code formatting rules across the repository. |
| `.eslintrc.cjs` | Establishes static code analysis rules for maintaining code quality and consistency during development. |
